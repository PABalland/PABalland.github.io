# Workflow: Discovery

Question shape: "Who could replace [provider] for [buyer or use case]?"

1. **Specify the need.** IaaS, PaaS, managed Kubernetes, HPC, GPU capacity, productivity suite hosting. Substitution depends on the component.
2. **Certified supply.** Pull the certification registers for the relevant country and list providers with the right scope.
3. **Search by capability, not by known names.** Query "[component] + [certification] + [country]" in the national language. Do not search "competitors of [known provider]", which only finds names you already have.
4. **Track record.** For each candidate, find at least one public contract award of comparable size.
5. **Ownership.** Confirm each candidate's control country with a corporate record. Several "European" providers have been acquired by non-EU groups.
6. **Gaps.** Say plainly where no EU-controlled substitute with a comparable track record was found.

Output: candidate table (provider, control country, certification, largest public award found, confidence), plus D2 rows for each candidate.
