# Counterfactual Check

Run this on every claim at STRONG INFERENCE or above, before writing the narrative.

1. **If this were false, how would I explain my evidence?**
   Example: the ministry's domain resolves to a US hyperscaler's IP range. Alternative: only the public website is there, and the sensitive system runs elsewhere.
2. **What single piece of evidence would disprove it?**
   Name it, and add it to Recommended Next Steps.
3. **Do my sources agree?**
   If a minister says "hosted in France" and the sub-processor list names a US parent, both can be true. Report both and explain.

Downgrade the claim one level if the alternative is as plausible as your reading.
