# French briefing (France, Belgium, Luxembourg)

## Terms that find things
| Concept | Use | Avoid / trap |
|---|---|---|
| Hosting | hébergement, hébergeur | "hosting" alone returns web-hosting ads |
| Contract award | avis d'attribution, attributaire, titulaire du marché | "contrat" is too vague |
| Framework | accord-cadre, marché subséquent, centrale d'achat (UGAP) | framework membership is not usage |
| Sub-processor | sous-traitant ultérieur | appears in RGPD annexes and privacy notices |
| Sensitive data | données sensibles, données de santé | |
| Certification | qualification SecNumCloud (ANSSI) | "cloud souverain" is mostly marketing; "cloud de confiance" was a government label for qualified offers, check current usage |
| Extraterritorial law | extraterritorialité, Cloud Act, immunité aux lois extraterritoriales | |
| Exit | réversibilité | |

## Where relationships are disclosed
- BOAMP and TED award notices.
- Questions écrites (Assemblée nationale, Sénat) and ministerial answers.
- Cour des comptes reports, CNIL decisions.
- Privacy notices listing sous-traitants ultérieurs.
- Belgium: e-Procurement (publicprocurement.be), federal answers to parliamentary questions. Luxembourg: marches.public.lu.

## Policy frame to check (dates matter)
- Doctrine « cloud au centre » (state circular, updated since 2021) and its rules for sensitive data.
- Loi SREN (2024) provisions on hosting of sensitive public data.

## Leads (training knowledge, NOT verified)
- Providers: OVHcloud, Outscale (Dassault Systèmes), Scaleway (Iliad), Cloud Temple, NumSpot (consortium).
- Split-model joint ventures: S3NS (Thales, Google technology), Bleu (Orange and Capgemini, Microsoft technology).
- Health Data Hub hosting on Microsoft Azure has been debated for years; check the current status and any migration plan.
- Luxembourg: a sovereign offer combining a national operator with Google technology has been reported; verify name and ownership.

## Structural vs naive queries
- Naive: "cloud souverain France" (returns marketing).
- Structural: "avis d'attribution hébergement données ministère 2026 2025", "« sous-traitants ultérieurs » hébergement plateforme", "question écrite hébergement données Microsoft ministère réponse".
