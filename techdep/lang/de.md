# German briefing (Germany, Austria)

## Terms that find things
| Concept | Use | Avoid / trap |
|---|---|---|
| Hosting / operator | Hosting, Betreiber, Rechenzentrum | "Cloud" alone is too broad |
| Contract award | Zuschlag, Zuschlagserteilung, Auftragnehmer, Bekanntmachung vergebener Aufträge | |
| Framework | Rahmenvertrag, Rahmenvereinbarung | framework membership is not usage |
| Sub-processor | Unterauftragsverarbeiter | in DSGVO annexes |
| Certification | C5-Testat (BSI) | C5 is an attestation, not a sovereignty label |
| Sovereignty | digitale Souveränität, souveräne Cloud, Abhängigkeit von US-Anbietern | |
| Public administration cloud | Deutsche Verwaltungscloud, Bundescloud, ITZBund, BWI | federal IT often buys through ITZBund or BWI, not the ministry |

## Where relationships are disclosed
- service.bund.de, DTVP, evergabe-online, TED.
- Bundestag Kleine Anfragen and answers (DIP database): the richest source for federal dependencies.
- Bundesrechnungshof reports, BfDI and Länder DPA decisions.
- Handelsregister and Unternehmensregister for ownership.
- Austria: USP / BBG (Bundesbeschaffung), BRZ (Bundesrechenzentrum), parliamentary Anfragen.

## Structural vs naive queries
- Naive: "souveräne Cloud Deutschland" (marketing).
- Structural: "Kleine Anfrage Abhängigkeit Microsoft Bundesverwaltung Antwort 2026", "Zuschlag Cloud Rahmenvertrag ITZBund 2025", "Unterauftragsverarbeiter Liste Verwaltungsportal".
